# Для дизайнеров и фрилансеров

## Если у вас Windows
1. Скачайте:  
   https://github.com/x3-team/monolit/releases/download/studiogate-v0.1.0/StudioGate-0.1.0-windows-x64.zip
2. Распакуйте архив
3. Откройте папку `win-unpacked`
4. Запустите `StudioGate.exe`
5. Вставьте ссылку студии (вам пришлют)
6. Войдите email/паролем
7. Нажмите **Open** у Figma

## Если у вас Mac
Попросите у владельца студии файл `StudioGate.dmg`  
(он соберёт его командой `npm run dist:mac` и пришлёт вам).

Потом: установить → вставить ссылку студии → войти → Open Figma.

## Linux
Обычно не нужен. Если очень надо — AppImage есть в Releases.

Пароль Figma вам не нужен.

# Для дизайнеров и фрилансеров

Вам **не нужно** вставлять ссылку сервера.

1. Скачайте StudioGate (Windows zip / Mac dmg)
2. Откройте приложение
3. Войдите email + паролем, который дал владелец студии
4. Нажмите **Open** у Figma

Ссылка на наш сервер уже внутри приложения.

Если не открывается — напишите владельцу студии.

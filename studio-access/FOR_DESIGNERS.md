# Для дизайнеров и фрилансеров

Вам **не нужен** GitHub-репозиторий и npm.

## 1. Скачать приложение
Откройте релизы:
https://github.com/x3-team/monolit/releases

Скачайте StudioGate для своей ОС:
- Mac → `.dmg` (когда появится в релизе)
- Windows → `.exe` (когда появится в релизе)
- Linux → `StudioGate-0.1.0.AppImage` уже есть

## 2. Установить / открыть

## 3. Вставить ссылку студии
Её пришлёт владелец (например `https://gate.yourstudio.com`).
Один раз.

## 4. Войти
Email + пароль StudioGate (тоже пришлёт владелец).

## 5. Нажать Open у Figma
Пароль Figma вам не нужен.

Если не открывается — напишите владельцу студии.

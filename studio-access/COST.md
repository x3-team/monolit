# Ценник на генерацию (StudioGate Cost)

Автоматический учёт AI-кредитов **по проекту** — без ручного Excel.

## Экран для продюсера

В `/app` блок **«Затраты на генерации»**:

1. **Крупная цифра** — сколько ₽ съел AI за текущий месяц
2. **Прогресс по всем бюджетам** — общая доля AI от бюджетов проектов
3. **Карточки проектов** — сумма ₽, кредиты, progress-bar бюджета
   - бирюзовый &lt; 80%
   - жёлтый ≥ 80% («близко к лимиту»)
   - красный ≥ 100% («бюджет превышен»)
4. История списаний — свёрнута под details

Фрилансер видит упрощённо: «Ваши генерации» + своя сумма за месяц.

## Как работает

1. Owner создаёт **Project** (имя, клиент, бюджет ₽).
2. Перед **Open Higgsfield** дизайнер выбирает активный проект.
3. StudioGate открывает сессию `UsageSession` (кто / какой проект / с какого времени).
4. **Обновить** (Sync):
   - `demo` (по умолчанию) — оценка кредитов по времени Open (~0.4 cr/min), чтобы показать продукт на пилоте без API.
   - `api` — импорт транзакций по Cloud API key (`KEY_ID:KEY_SECRET`), атрибуция по пересечению с Open-сессиями.
5. Отчёт: кредиты → ₽ (`creditPriceRub`) → маржа vs бюджет проекта.

## Почему не «все AI-инструменты сразу»

У каждого вендора свой биллинг. Реалистичный MVP: **Higgsfield полностью**, остальное — по одному коннектору.

Общий web-аккаунт Higgsfield **не знает**, кто из дизайнеров нажал Generate. Атрибуция идёт через **окно Open в StudioGate** (время + проект). Если двое Open одновременно на одном аккаунте — кредиты делятся поровну.

## Пилотная проверка

```bash
cd studio-access
npm run db:setup
npm run dev
```

1. Войти `owner@studio.local` / `owner123456`
2. Mark connected (demo) на Higgsfield
3. Выбрать проект «Nike…»
4. Open Higgsfield
5. «Обновить» → увидеть крупную сумму месяца и progress-bar на проекте

# StudioGate — скрипт продажи (15 минут)

## Кому звонить
Продюсеры / владельцы design & AI-студий 5–30 человек, которые шарят Figma и Higgsfield с фрилансерами.

## Оффер
«Фрилансеры работают в Figma и Higgsfield без паролей. После проекта доступ снимается в один клик. Биллинг остаётся только у вас.»

## Демо на созвоне
1. Открыть http://localhost:3001 (или ваш деплой)
2. Войти: `owner@studio.local` / `owner123456`
3. Mark connected (demo) на Figma и Higgsfield
4. Invite freelancer
5. Показать Open + Audit log
6. Revoke в один клик
7. Для live: `npm run desktop` → Connect team-аккаунтом (не billing)
